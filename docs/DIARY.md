# 日记（桌面，v1）

> 261109 立项。**数据 = 笔记本体系内的普通 Lake 文档；表现 = 独立空间。**
> 本文只写我们自己的契约与决策（机制参考见下「来源」）；不写进度/分支，那些在 `docs/HANDOFF.md`。

## 决策（用户 261109 定稿）

1. **存储完全依托笔记本体系（D2）**：日记 = 一个带标记的笔记本；**不新建数据空间、不新建表**。正文/历史快照/回收站/FTS/导出/备份/便携包全部复用文档那一套。
2. **表现 = 独立空间**：侧栏「空间」组第 4 项（文档 ⌘1 / 小记 ⌘2 / AI 写作 ⌘3 / **日记 ⌘4** / 标签），与文档目录树解耦。
3. **标题即日期** `YYYY-MM-DD`；层级 `日记 → 2026 → 11 → 2026-11-09`，**年/月两级分组自动创建**（group 节点，随 `folders[]` 同步）。
4. **没有旧端**：允许加 wire 字段，不需要为旧客户端写降级。
5. **v1 不做**：缺天提示、补写入口、月历视图（见「不做」）。
6. **v1 只做桌面**；移动端本期只保证「能在日记本里写今天」（复用现有工作区，不加空间页/第 4 个 tab）。

## 标识与 wire

| 层 | 形状 | 说明 |
| --- | --- | --- |
| wire | `LakeFolderEntry.kind?: "diary"` | `folders[]` 本来必填，随 lake 索引同步 |
| 桌面本地 | `tree_nodes` 加列（schemaInit） | 与 wire 同义；发布时从该列投影 |
| 移动本地 | 同名列，`MOBILE_SCHEMA_VERSION` +1 | 改表必须 +1（AGENTS §4） |

**一致性硬规则**：发布时**必须显式写 `kind`**（非日记写 `null`，不是省略）——否则「取消日记标记」在 wire 上不可见、两端会互刷（同标签 `tagIds` 空集合必须写 `[]` 的教训）。
读取：缺字段 = 非日记；出现 **多个** `kind=diary` = 取第一个并记日志告警，**不自动修复**（不替用户做数据决定）。

## 信息架构

- 空间 id `diary`，菜单第 4 项，快捷键 **⌘4**；shell class `diary-space-active`；keep-alive 分区（与 `ai-writing` 同构）。
- **左栏（280px）**：年 → 月 折叠清单（当前年/月默认展开）+ 底部「日记本设置」（改名/换图标/定位到今天）。
- **主区**：今天那篇的**现有编辑器**（`EditorTab`，不新写编辑器）；空态 = 「写今天」主按钮 + 最近 7 天入口。
- **文档空间**：目录树**不显示**日记本（渲染层过滤，不改存储）；日记文档仍在全局全文搜索里（自己的日记搜得到是刚需），**不进标签空间**。

## 数据与幂等

- 打开今天：在日记本内按 **标题 = 今天** 查 `tree_nodes` → 命中则打开；未命中则建（缺失的 年/月 group 一并建）。
- 整个创建流程进**写域**（`KeyedAsyncQueue`，禁同域嵌套 ⇒ I3），**连点不会建出两篇**。
- 建完**只展开到今天这个节点**，不刷新整棵树、不抢正文焦点（参考思源 issue：「创建日记时不再展开文档树」）。
- **失败分级**：日期解析失败 = 拒绝创建 + 明确报错；正文模板失败 = 只告警、空文档保留（绝不因模板坏而丢建档）。
- 首次进空间：**自动创建**「日记」笔记本并打标记（不让用户去设置里选）；已存在则复用。

## 不做（v1 明确，别再立项）

缺天提示 / 补写任意日期 / 月历视图 / streak / 提醒 / 心情·天气·位置字段 / 移动端空间页。
理由：§3#17 三问未过（补写与月历在 v1 是"以后可能需要"，不是已验证痛点）；月历还会与多维表月历撞「同一交互语义只有一套视觉」红线（`audit-lookalike.mjs`）。

## 护栏（新增测试必须覆盖）

1. 幂等：同一秒连点两次「今天」只产生一篇文档。
2. 日期键：`YYYY-MM-DD` 解析/格式化只走一个纯函数（跨时区必须取本地日期，参考多维表日历的「绝不走 UTC」）。
3. wire 往返：`kind` 发布时显式写（含 `null`）；旧索引缺字段读成非日记；多标记只取第一个且告警。
4. 树过滤：文档空间的目录树不出现日记本；日记空间能看到年/月结构。
5. 移动 schema 版本门：加列必须 +1 且冷启动不重复执行。

## 来源（机制参考，不是抄实现）

- 思源 v3.8.4 日记：路径模板 + IAL 标记 `custom-dailynote-YYYYMMDD`、先查后建的幂等、模板只在新建时套用（`kernel/model/file.go:1436`）。
- 思源的坑（我们不学）：中间路径段变成真文档 / 内核写死 `time.Now()` 无法补写 / 幂等键是标题路径 / 日记本只存在前端 localStorage。
