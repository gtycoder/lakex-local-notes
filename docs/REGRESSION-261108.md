# 发版前 UI 回归记录（261108）

> 目标：用真实前端 UI 点击/输入触发桌面端与 Android 端关键路径，逐项记录「预期 → 实际 → 差异」，发现差异定位并修复。
> 环境：桌面 Electron dev（隔离用户数据 `/tmp/lake-regression-user`，CDP 9222）；Android gate AVD（lake_gate，emulator-5556，CDP 9336）。
> 方法：CDP `Input.dispatchMouseEvent` / DOM `element.click()` / 触摸长按，均走页面真实 React 事件；未直接改数据库。

## 结果总览

- 已执行 25 组桌面检查 + 6 组 Android 手机检查 + 3 组平板检查，**未发现功能性报错或数据错误**。
- 发现 1 处文档问题：`guide/08-search-outline-tags.md` 仍写「标签只用于小记，不给文档打标签」，与现状不符；已修正（文档标签、标签空间、Android 标签页、批量打标签）。
- 1 次测试脚本误判：「批量创建副本」首轮只创建 1 份，原因是脚本未清空上一轮多选，实际只选中 1 行；清空后选中 1 行的副本数 = 1，符合预期，不是产品问题。
- 未覆盖：S3 冲突留档/被覆盖恢复、附件资产传输、AI 外部服务、桌面原生文件选择器、Android 系统分享/文件导入；其中 S3 已覆盖配置、拉取、上传、跨设备删除传播，冲突与附件仍待补。
