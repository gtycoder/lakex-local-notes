## defaultFontsize
`<font style="color:#7E45E8;">number</font>`

默认字号。但不会对标题、卡片等的字号生效。

需要注意默认字号是有设定限制的，目前支持的字号如下：

```javascript
export const DEFAULT_FONTSIZES = [12, 13, 14, 15, 16, 19, 22, 24]; 
```
