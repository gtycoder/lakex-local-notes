## supportEmoji
`<font style="color:#2F4BDA;">boolean</font>`

emoji 使用独立的字体，让以前会渲染错误的 emoji 可以尽量正确的渲染

```javascript
const opt = {
  kernelAssistant: {
    supportEmoji: true,
  },
};
```
