# 配置项
## KaTexURL
`<font style="color:#7E45E8;">string</font>`

katex的umd资源地址。不建议配置该项。

## hideOnInvisible
`<font style="color:#7E45E8;">boolean</font>`

根据`intersectobserver`判断公式卡片不可见时是否隐藏节点以提升渲染性能。默认为`false`
