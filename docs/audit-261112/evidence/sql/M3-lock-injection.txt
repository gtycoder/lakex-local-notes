为什么用 DB 注入锁状态：本机不配置 S3（不碰真实桶）⇒ 无法跨端同步。移动端同步落地锁的写入就是
UPDATE notes SET is_locked=?, locked_at=?（src/mobile/v3/mobilePlatformPort.ts:374-379），
与本次注入同一字段/同值；桌面侧产生该状态的是 setNoteEditLocked → is_locked=1（electron 元数据写）。
步骤（App 先 force-stop，离线写，再启动，等价于"同步落地后首次打开"）：
  adb shell am force-stop com.lakexlocalnotes.android
  adb shell 'run-as com.lakexlocalnotes.android sqlite3 databases/lakex-local-notes-mobileSQLite.db \
    "UPDATE notes SET is_locked=1, locked_at=2026-11-12T09:25:00.000Z WHERE id=<id>; ..."'
  → SELECT ... → 7b6b59ef-...|1|2026-11-12T09:25:00.000Z
  adb shell am start -n com.lakexlocalnotes.android/.MainActivity
  → 重启后再查仍为 is_locked=1（App 未复位）
