欢迎来到 Lake Notes

这是一个基于 Lake 编辑器的本地优先笔记应用（Electron 桌面端）。把鼠标移到段落上，左侧会出现块手柄——它需要块左缘外 54px 的槽位。

目录栏收起时只留一条隐形热区；指针接近才浮出把手。这样正文不必为"缩略图条"让出 39px（旧方案要 93px，新方案只要 54px 的手柄槽）。

  • 固定：面板占住左槽、正文被推开
  • 悬浮：同一个盒，浮在正文上
  • 触发条：可隐藏，指针接近才出现

目录栏三态（交互原型）

• 固定：占左槽 0..W，正文左内距 = W+62；连体面 + 1px 分隔线
• 悬浮：同一个盒，浮在正文上（投影 + 右侧圆角），不推正文
• 触发条：默认隐藏；指针接近左缘才浮出把手（跟手 Y）。可点"常显细条"
快捷键：⌘\ 固定/隐藏 · Esc 收起悬浮 · 拖面板右缘调宽
