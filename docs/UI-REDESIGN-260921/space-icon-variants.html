A · 图标嵌进工作空间钮（推荐）

18px 软底小方块装当前空间图标，紧挨「本地空间 ▾」。一整块可点，菜单里可切空间。

直观：图标即空间；省：并进既有控件，几乎不加宽；融洽：像 macOS「位置」前的图标。

最融洽 · 推荐

B · 独立小图标钮

左侧单独一枚 28px 图标钮（仅图标），旁边仍是工作空间钮。两枚控件，语义最清晰。

适合「空间」与「工作空间」要完全分开点的场景；略多 ~32px。

最清晰

C · 色点角标

工作空间钮左侧一枚 6px 色点表示当前空间（蓝/橙/红）。极致省，但色点语义弱、不可点独立切换。

只适合「扫一眼知道在哪」，不适合当主切换入口。

最省 · 语义弱
