悬浮把手 · 无固定边栏

保留全部功能 · 只改交互外观 · 顶栏不放固定按钮
怎么用　把鼠标贴左/右把手 → 浮出；点整条 → 弹出面板； 点把手上的 📌 → 固定（推开正文）；再点 📌 → 取消固定回悬浮。顶栏没有固定控件。

H-A / H-B / H-C / H-D

  • H-A 胶囊浮条 — 竖向玻璃胶囊 + 标签「目录」，信息量最高
  • H-B 圆球 + 轨 — 小圆轨 + 独立 📌 球，最「轻」
  • H-C 缺口把手 — 从窗口边缘凸出的半圆，最不占注意力
  • H-D 双点条 — 飞书文档感，hover 才长出玻璃壳

空间规则（更正版）

  • 资料库 — 有目录 + 增强大纲（右侧同款）
  • 小记 — 纯工作台（卡片流），无目录、无大纲，把手自动隐藏
  • 回收站 — 纯工作台（删除列表），同样无目录、无大纲

原生内核大纲：完全不动，仅编辑器内自带开关。

大纲

H-A · 垂直胶囊浮条

玻璃胶囊 + 竖排「目录/大纲」标签 + 📌。整条可点弹出，标签也在条上。信息清晰，略占视觉。

H-B · 圆球 + 轨迹条

细轨道把手 + 独立 📌 小球。最轻、最不挡正文；语义略隐晦（要 hover 才懂）。

H-C · 缺口半圆把手

从窗口边缘凸出的半圆，像抽屉拉手。完全不侵占正文，点击即拉出；📌 在把手下。

H-D · 双点飞书条

默认极淡双点/短轨（飞书文档感），hover 长出玻璃壳。安静、现代；发现性靠试。
