操作模型　无左侧固定活动栏。左/右各有一条 10px 热区贯穿全高： hover 或点击 → 面板滑出（悬浮）；点 📌 → 固定 并推开正文。目录与大纲各自独立记固定态。

1. 三个空间完全独立

  • 资料库 —— 笔记 + 目录树
  • 小记 —— 无目录；卡片/列表工作台独占
  • 回收站 —— 独立列表空间
  • 顶栏分段 = 空间切换（整页替换），不是侧栏菜单展开

2. 目录：悬浮 + 固定（L2 下也可常驻）

  • 悬浮：覆盖在正文上，不占宽（默认，可视最大化）
  • 固定：占 grid 列推开正文，等价现在的「固定侧栏」
  • 状态可分别记忆；顶栏 ☰ 按钮带钉点表示已固定

3. 增强大纲（右侧，目录同款）

  • 与左侧目录同构：热区 → 悬浮 → 可固定
  • 行样式 = nav 同款（选中 tint + 字重）
  • 原生内核大纲完全不动（右上角徽标仅示意）
  • 用增强大纲时，右侧栏可完全收起 = 右侧 0 占用
