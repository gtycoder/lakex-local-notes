S1 · 并入工作空间下拉（推荐）

就是你提的：空间进下拉。回收站已在该菜单，合并后语义更干净。

  • 顶栏 +0 控件 · 无活动栏
  • 菜单：空间（⌘1–3）+ 设置/历史
  • 与真实产品菜单同源，迁移成本最低
  • 代价：当前空间名不在顶栏常显（可在面包屑重复）

S2 · 一枚「空间」钮

顶栏只加一枚钮，显示当前空间名+图标，点开下拉。比三分段省一半。

  • 占用 ≈100px · 当前空间可见
  • 工作空间菜单仍可保留（设置/历史）
  • 两枚下拉略近，需拉开或合并

S3 · 三枚窄图标（无字）

比 S2 更省一截，一键直达；但发现性弱（要 hover 看 title）。

  • 占用 ≈90px · 一键切换
  • 适合熟练用户
  • 图标语义需 lucide 对齐（Files/Feather/Trash）

S4 · 左缘热区兼空间切换（最省）

顶栏完全不放空间控件；左缘滑出面板，顶部固定空间列表，下面是目录树。

  • 顶栏 0 · 无活动栏
  • 空间与目录同一手势入口
  • 代价：看不见当前空间；可面包屑补字
