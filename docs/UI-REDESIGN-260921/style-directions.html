UI 重构方向

今天 09:18 · 已同步 · 1,284 字

目标是精简套壳层数，几乎完全剥离思源样式；刚需件（细滚动条等）仿照自研，先收口结构，再重做更高级的视觉。

当前判断　架构（@layer + 令牌 + kit）可续用；视觉层需要换方向。下面三版是令牌级对照，不改业务逻辑。

为什么不是推倒重来

  • 桌面 var(--b3-*) 已归零，加样式不会再叠级打架
  • 新层选择器平均特异性 1.1–1.6，嵌套深度 1–2
  • 主题即数据：换肤只动 themes/*.css

下一步

选定方向后，把色板与组件规格写回主题文件，并继续把 legacy 屏迁到单轨 ln-*。

A · MiMo Desktop 亮面

照你截图气质：近白侧栏、大留白、软阴影卡片、蓝点缀。最接近「简洁大气」，适合先做默认浅色。

B · Obsidian 暗面

更高密度、紫点缀、深底。工具感更强，适合当深色主题基线（或独立「专注」皮肤）。

C · MiMo × 笔记（推荐）

在 A 的结构上把主色换成 MiMo 橙、侧栏略沉一档、阅读区保持纯白纸面。更有记忆点，也更像个人笔记。
