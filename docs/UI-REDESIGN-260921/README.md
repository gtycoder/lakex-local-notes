## 3. 目标架构

### 3.1 层序（CSS `@layer`）

`@layer legacy, tokens, reset, kit, shell, feature, overlay, a11y;`

- **`legacy` 是最低层**：新层一旦写入即自动压过旧样式，**迁移期不需要靠特异性/顺序取胜**。
- legacy 内部相对顺序逐字不变 ⇒ **引入当天 0 视觉变化**（可截图验证）。
- 迁移 = 把某元素的 legacy 规则删掉 + 在对应新层写入；每屏独立可验。
- ⚠️ `!important` 的层序是**反的**（早层重要声明赢），所以 legacy 里残留的 `!important` 仍会压过新规则——**每个元素的 legacy 规则必须连同 `!important` 一起删干净**。
- 旧样式统一走 `@import ... layer(legacy)`，入口文件 `src/styles/index.css`，由 `main.tsx` 引入。

### 3.2 主题即数据

`src/styles/themes/{light,dark,warm}.css`：每套只定义变量（`[data-theme=...]` 覆盖 `:root`），结构/几何/动效不随主题变。
`src/styles/themes/index.ts`：主题注册表（id / 名称 / 色卡预览 / colorScheme）。
新增主题 = 加一个 css + 注册表加一项，**不改任何组件代码**。
第三方桥接（内核 `--lakex-editor-*`、FortuneSheet、drawnix）**只做变量映射**，自定义主题一律**回退映射到 light/dark 二值**（drawnix 只认这两个）。

### 3.3 组件库

14 件（`ln-*` 命名，落在 `kit` 层）：按钮 / 图标按钮 · 列表与列表项 · 菜单(含子菜单·右键·遮罩) · 对话框(scrim·头·内容·操作区) · 提示条 · 输入框(含搜索) · 下拉选择 · 开关 · 徽章与标签 · 卡片 · 气泡 Tooltip · 分段控件 · 滚动条 · 表单行。
规格严格按设计包 `COMPONENTS.md`（六态 / 变体 / 令牌依据 / do-don't）。

### 3.4 字体（可替换）

- 三处令牌：`--lake-font-family`（界面）· `--lake-font-family-reading`（正文）· `--lake-font-family-mono`。
- 技术事实：内核**没有**字体变量，但编辑器正文字体**已是我们自己的规则**（`src/styles/editor.css` 的 `.lake-editor-mount .ne-viewer-body`）⇒ 属外围，不算改内核。
- 开发期试用切换器：仅 dev、不进设置项、不落盘；候选清单见 `02-FONTS.md`。

## 6. 边界（红线）

- **lakex 编辑器与 `src/mobile/**` 零改动**；`vendor/**` 不动。
- **不改业务逻辑 / 数据 / 同步语义**；只做结构性换皮。
- 不新增运行时依赖。
- 遇到必须大改动才能解决的点 → **记录为已知未做并绕过**，不阻塞整体；遇到要改逻辑/要删功能 → 停下写文档等用户。
