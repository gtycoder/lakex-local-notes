## 1. 设计目标（不可漂移）

1. **最大化可视空间**：无左侧固定活动栏；目录/大纲默认可整栏收起。
2. **保留全部功能**：只改样式与壳层交互，不改业务逻辑 / 数据 / 同步语义。
3. **风格**：清透质感（HyperOS 向）——轻玻璃只在外壳/浮层，正文区不用毛玻璃，大留白。
4. **原生内核大纲零改动**（闭源冻结区）；目录与增强大纲 = 外壳自研，手势对齐原生。

---

## 2. 空间模型

三个**完全独立**的空间（整空间替换，不是侧栏菜单展开）：

| 空间 | 图标（lucide） | 内容 | 目录 | 大纲 |
| --- | --- | --- | --- | --- |
| **资料库** | `Files` | 笔记目录树 + 文档/表格/多维表/画板 | ✅ | ✅ 增强大纲 |
| **小记** | `Feather` | 卡片流 / 列表工作台 | ❌ | ❌ |
| **回收站** | `Trash` | 删除管理工作台 | ❌ | ❌ |

- 小记 / 回收站下：整边热区与面板**自动隐藏**，正文铺满。
- 空间切换 = 替换整个工作台（标签页、侧栏、大纲配置一起换）。

## 3. 空间切换 = S1 + A 图标（定稿）

### 3.1 入口

并入顶栏**工作空间钮**（真实产品 `DesktopTopBarLeading` 的位置）：

```
[● ● ●]  [🟦 本地空间 ▾]  [☁ 待同步]   |  页签…  |  [▾] [🔍]
          └─ A 嵌法：18px 软底小方块内为当前空间图标
```

- **A 嵌法**（用户选定）：`18×18` 圆角 5px 软底（`--lake-accent-tint`）+ 空间图标（12px，`--lake-accent-text`）+ 工作空间名（本地空间 / S3 前缀）+ `ChevronDown`。
- **整块可点** → 打开合一菜单。
- 顶栏**不**放三分段空间切换；**无**左侧固定活动栏。

### 3.2 合一菜单（`top-menu--workspace` 扩展）

```
空间
  [Files]   资料库           ⌘1
  [Feather] 小记             ⌘2
  [Trash]   回收站           ⌘3
────────
工作空间
  [Settings] 偏好设置
  [History]  历史快照…
```

- 当前空间带 `Check` 勾选 + `accent-tint` 底。
- **回收站不再作为「打开面板」菜单项**，改为空间进入（与资料库/小记同级）。
- 快捷键：**⌘1 / ⌘2 / ⌘3**（Win：Ctrl+1/2/3）。

### 3.3 工作空间名规则（沿用 `workspaceName.ts`）

云同步已启用且存在 S3 `prefix` → 显示 prefix；否则 **本地空间**。

## 4. 整边触发（对齐云端 Lake 原生大纲手势）

### 4.1 触发区

| 侧 | 宽 | 范围 | 行为 |
| --- | --- | --- | --- |
| 左（目录） | **14px** | 顶栏下 → 窗口底（**全高**） | hover ≈120ms 自动弹出 |
| 右（增强大纲） | **14px** | 同上 | 同上 |

- **不是**球、不是短条；鼠标贴边任意高度即可。
- 可见反馈：整边柔光渐变 + 中部 `☰` 图标（极淡，hover 增强）。
- 点击边或 `☰` = 显式弹出/收起。

### 4.2 面板：悬浮 / 固定

| 模式 | 表现 |
| --- | --- |
| **悬浮**（默认） | 覆盖在正文上，不占宽；圆角朝内 + 1px 描边 + 投影；移出面板且未固定 → 自动收回 |
| **固定** | 占 flex 一列**推开正文**（无空白叠宽）；去投影/圆角，与主区分界 1px |

- **📌 在面板头**（不在顶栏）：点击切换固定/取消固定。
- **✕** 收起并取消固定。
- 目录与大纲**各自独立**记忆固定态。
- 固定且打开时，对应边区让到面板外侧，仍可整边再触发。

### 4.3 可调宽

- 拖拽面板**内缘**手柄（6px 热区，hover 显示 3px 竖条）。
- 范围 **200–420px**；宽度写本机（localStorage / device_state，**不进 S3**）。

### 4.4 目录 vs 大纲

| | 目录（资料库） | 增强大纲 | 原生内核大纲 |
| --- | --- | --- | --- |
| 实现 | 外壳自研 | 外壳自研 | **内核，零改动** |
| 手势 | 整边 / 📌 / 调宽 | 同左 | 内核自有 |
| 行样式 | kit `.ln-row` 族 | 同目录（lv2/lv3 缩进） | 不改 |
| 数据 | `tree_nodes` | 标题块收集 | 内核 TOC |

- 增强大纲面板顶部可放一条说明：「原生内核大纲不在此（编辑器内开关）」。
- 设置项 `editor-outline-enhance` 继续控制是否使用增强大纲。

## 5. 顶栏（保留真实产品元素）

结构对齐 `MultiTabEditor` 的 `.tab-bar` 融合条：

| 槽位 | 元素 | 来源 |
| --- | --- | --- |
| leading | 红绿灯（macOS） | 壳 |
| leading | **空间图标 + 工作空间名 ▾** | 本规格 §3 |
| leading | **云同步**（四态图标 + 文案） | `SyncStatusPopover` |
| center | 页签：脏点 · 钉 · 关闭 · **已删除徽标** · 拖拽 | `MultiTabEditor` |
| center | **标签切换器 ▾** | 同上 |
| trailing | **全文搜索** | `DesktopTopBarSearch` |

- 面包屑行保留（32px）：`笔记本 / 文档`，超长 **clip 不打省略号**（产品既有决策）。
- 状态栏保留：字数 · 图片 · 同步状态胶囊。
