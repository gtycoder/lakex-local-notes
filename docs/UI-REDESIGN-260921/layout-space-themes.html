最大化可视空间

设计目标 · 全部边栏可收起 · 默认悬浮弹出 · 阅读优先
L2 推荐　顶栏仅 36px 玻璃条；目录 / 大纲 / 状态全部悬浮或胶囊，正文铺满。 这是对你「可视空间最大化」最直接的布局；L1 作对照，L3 介于两者之间（可钉住推开）。

三套布局怎么选

  • L1 思源式常驻 —— 与当前产品一致：活动栏 + 目录 + 正文 + 底栏；收起目录即变宽。稳妥、迁移成本最低。
  • L2 极简悬浮（推荐） —— 无常驻侧轨；目录/大纲为覆盖层，状态栏变右下胶囊。正文宽度最大（约 92–100%）。
  • L3 边缘热区 —— 默认全宽；左缘 hover/点击滑出目录，可「钉住」推开内容；大纲同理。接近 VS Code / Obsidian。

主题映射（A/B/C 全保留）

  • A 亮·蓝 —— MiMo Desktop 气质，近白侧栏 + 蓝点缀 → 默认浅色
  • C 亮·橙 —— 同结构换 MiMo 橙主色，更有笔记记忆点 → 浅色备选
  • B 暗·紫 —— Obsidian 向深色，分层 + 1px 描边，避免糊成一团 → 深色模式基线

风格基调遵循设计包：「清透质感 · 轻玻璃只在外壳/浮层 · 正文区不用毛玻璃 · 留白拉开层级」。
