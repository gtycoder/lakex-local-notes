## 8. 语雀**没有**的东西（边界，别照抄成缺陷）

1. **行/列结构操作**（插入/删除行、列、移动）在移动端**没有任何入口**；
2. **没有长按上下文菜单**（剪切/复制/粘贴、插入/删除行列都不在移动端提供）；
3. 没有「更多表格工具」**底部面板**（所有二级能力都在顶部锚定卡片里）；
4. 没有独立的「编辑/阅读」两套工具记忆（读态工具条只留视图类 5 项）；
5. **没有版本/发布**之外的保存语义：「更新」是发布态按钮（`larkui-popover-trigger`，打开更新/发布浮层，**具体行为待确认**）。

## 10. 复刻方案（我们的技术，不改数据）

### 10.1 骨架
1. **不加文档头行**（我们已有工作区顶栏；语雀那行是它 web 应用自身的壳）——改为：顶栏右侧 `⋯` 打开文档菜单，保存状态放工具条右端。
2. 工具条：40 高、`--lake-bg-subtle`、上下 1px `--lake-border-1`、按钮 34×32 / radius 3（新原语 `.mb-sheet-btn`）。
3. 公式栏：21 高 / 地址 40 / 12px。
4. 底栏：**自绘 32 高**（工作表菜单 / 页签 / ＋ / 缩放），关闭 Univer 自带底栏（样式与语义都对不上）。

### 10.2 浮层：新增移动端原语 `.mb-popcard`（锚定卡片）
- 锚到触发按钮下方（复用 `usePopoverPosition` 的量测思路 + 移动端 `floating.css` 的层序），**不是** `MobileSheetMenu`（后者保留给设置/属性这类"大而整"的菜单）。
- 规格照 §5：底色、8px、34 高行、图标 20 + 标题 14、分割线、子菜单右展开；**不写颜色字面量**（映射：`#FAFAFA → --lake-bg-subtle`、`#E7E9E8 → --lake-border-1`、`#585A5A → --lake-text-2`、`#2F8EF4 → --lake-accent`）。

### 10.3 能力映射（Univer facade / 插件）

| 语雀能力 | 我们的落法 | 现状 |
| --- | --- | --- |
| 数据类型（文本/数字/百分比/货币/日期/时间/日期时间） | `FRange.setNumberFormat`（已接 9 档） | ✅ 已有，改成下拉+子菜单 |
| 小数位 ± | numfmt `0.0…` / `0` | ✅ 已有（只 +，缺 −） |
| 字号 / 字色 / 底色 / B/I/U/S | facade `setFontSize` / `setFontColor` / `setBackgroundColor` | ✅ 已接（字号未接） |
| 水平/垂直对齐 | `setHorizontalAlignment` / `setVerticalAlignment` | 水平 ✅ / 垂直待接 |
| 溢出 / 切断 / 换行 | `setTextWrap`（换行）；overflow/clip 走溢出策略 | 待接 |
| 合并 | `range.merge` | ✅ |
| 边框（11 预设 + 颜色 + 样式） | `setBorder` | 待接 |
| 冻结 | `setFrozenRows/Columns` | ✅ |
| 行高/列宽 | `setRowHeight/setColumnWidth/autoFitRow` | ✅ |
| 条件格式 | 需 ```univerjs/sheets-conditional-formatting` | ❌ 未装 |
| 筛选 / 排序 | 需 `sheets-filter` / `sheets-sort` | ❌ 未装 |
| 数据验证（下拉/复选框） | 需 `sheets-data-validation` | ❌ 未装 |
| 保护 | 需 `sheets-protection` | ❌ 未装 |
| 查找替换 | 需 `sheets-find-replace` | ❌ 未装 |
| 图表 | 需 `sheets-chart` 或自研图片渲染 | ❌ 未装（代价最大） |
| 链接 | facade hyperlink | 待接 |
| 图片 | drawing 插件（已装） | ✅ 已有粘贴图 |
| 附件 / 备注 | 我们**没有单元格附件/备注概念**（附件是文档级资源） | 语义不同，建议不做（决策 D4） |
| 公式库（分类） | facade `setFormula` + 自建分类表 | 只有 5 个 Σ 快捷 |
| 插入行/列 | 语雀移动端**没有** | 我们可保留（多一点不是坏事，决策 D6） |

> 补插件必须走 `docs/USHEET-UPGRADE.md` 的 playbook（`univerContract.test.ts` 静态护栏 + `scripts/usheet-kernel-probes.mjs` 运行时探针，一次全升、不要 npm update）。

### 10.4 画布样式（表格专用主题）
- 不改全局 `--lake-*`；给表格加一组移动端令牌（`src/mobile/theme/*.css`）：`--mb-sheet-bg / --mb-sheet-line / --mb-sheet-head-bg / --mb-sheet-head-text / --mb-sheet-select / --mb-sheet-select-fill / --mb-sheet-check`，在 `univerTheme.ts` 里让表格读这组值（单一来源仍只一处）。
- 参数：行高 **24**、默认列宽 **120**、行头 **41**、列头 **25**、默认字号 **12px**（语雀内部 9pt）；网格线 **#E7E9E8**；表头 **#F4F5F5** / 字 **#585A5A**；选中 **#2F8EF4** + 填充 `rgba(94,211,217,.1)`；复选框绿 **#00B96B**。

### 10.5 键盘与视口
- 语雀：adjustResize（WebView 变矮）。我们：Capacitor + `visualViewport`（`--kb-offset`）。
- 表格页要单独验证：键盘弹起时**公式栏/工具条保持可见、画布缩短、底栏贴键盘上沿**（与语雀一致）。

### 14.5 本批发现并修掉的两个真 bug

1. **面板长标签被省略号吃掉**（9 项一行 → 「常…」「数…」「货…」）：数字格式改 **5+4 两行**、常用公式 **3+2 两行**；
   `usheetNumfmt` 标签收短到 ≤4 字（常规 / 文本 / 数字 / 整数 / 百分比 / 货币（¥） / 日期 / 时间 / 日期时间），
   护栏加「标签 ≤5 字符」断言。dock 的数字格式按钮用 `--lake-font-size-tiny` + 46px 上限（3 个汉字不省略）。
2. **⌨ 收起来就再也弹不回去**：原判据是「焦点是否在宿主内」，但关闭键盘后 Univer 会把焦点留在编辑器 div
   ⇒ 永远走「收起」分支。改为 **视口收缩 >200px = 键盘开**（AGENTS §7.17 判据），并加双态图标。

### 14.6 残留 / 未做（如实记录）

- 撤销/重做**常亮**：Univer facade 没有 `canUndo/canRedo`（undo 栈在 `IUndoRedoService`，要拿注入器才能问），本批不引内部 API。
- 数字格式 / 字号在**整列/多格混选**时回显「常规」（只读活动格）。
- 筛选 / 排序 / 条件格式 / 数据验证 / 保护 / 查找替换 = **P2（要补 Univer 插件，走 USHEET-UPGRADE playbook）**；图表/快捷键面板不做。
- 阅读态轻工具条暂只有工作表 + 缩放（语雀还有筛选/排序/冻结/查找，等 P2 能力到了再补）。
- **网格默认只在移动端注入（B 方案，用户 261020 定）**：`src/core/usheetDoc.ts` 保持桌面口径（列宽 88、不写行头/列头），
  移动端新建表走 `src/mobile/usheet/mobileSheetGrid.ts` 的 `emptyMobileUsheetBody()`（24/120/40/24），
  「＋新建工作表」也把同一份 `MOBILE_USHEET_GRID` 传给 `insertSheet`（否则新页签会按内核默认 88 出来）。
  网格写进正文后**跟着文档走**：手机上建的表在桌面打开也是这套；旧文档一律不迁移。
- 撤销/重做按钮**跟随内核撤销栈置灰**（`IUndoRedoService.getUndoRedoStatus`，令牌从 `@univerjs/presets` 转发拿；
  触点已登记 `usheetKernelContract.ts` 的 `UNIVER_FEATURE_NAMES`）；服务缺席时退回常亮，不锁死。
- 文档头行（语雀 60 高那行）**不做**：我们已有工作区顶栏（D1 定稿）。
### 14.7 第二轮对齐：面板定高 + 类别键变 ×（261020 用户点单）

- **面板高度 = 捕获的键盘区高度**（`capturePanelHeight(keyboardHeight)`，来自 `mobile/editor/editSurfaceModel`，
  与文档 dock 同一套算术）：内容多则在 `.ush-panel__inner` 内部滚，内容少则下方留白；工具栏位置与内容视口恒定。
  实测：键盘开时 Aa（键盘高 312）→ 面板 top 530 / h **312**，`.ush-panel__inner` scrollHeight 328 > client 311（可滚）。
- **展开的类别键变 ×**（文档 dock 同款）：＋ / Aa / 常规 / ⋯ 任一展开后按钮变 `X` 且高亮；再点**一次** =
  关面板 + **把键盘放回来**（继续输入）；点网格 = 只关面板（不替用户拉键盘）；⌨ = 只关面板也不拉键盘。
- **面板开/关必须走 facade 的编辑态 API，不能只 blur**（真 bug，设备实测）：
  `openPanel` 用 `fWorkbook.endEditingAsync(true)`、关面板/⌨ 用 `fWorkbook.startEditing()`。
  **只 blur 的后果**：Univer 停在"编辑中"，移动 footer 从「开始编辑」变成「取消 / 确定 / 公式」，
  `button[aria-label="开始编辑（选区切换到编辑器）"]` 直接不存在 ⇒ ⌨ 与 × 都再也弹不回键盘。
  两个符号已登记 `univerContract.test.ts` 的 facade 清单（升级改名会当场红）。
### 14.8 第三轮对齐：面板收起过渡（closingHold）

- **收起不再"啪"地卸载**：面板关闭先进 `closing`（`data-closing="1"` → 期间 `pointer-events:none`），
  restore 档（×）内容**保持到键盘真上来**；键盘回来 150ms 后卸载，键盘迟迟不来 1800ms 后放行内容滑出、
  2500ms 兜底卸载 —— 与文档 dock 的 `useEditSurface.closePanel` 完全同口径。
- 退场期渲染沿用上一次的 panel（`renderedPanel`），不会先少一块。
- 实测（lake_sheet 专用 AVD）：点 × 后 t≈0 面板仍在（data-open=1 / data-closing=1，键盘 842）→ 键盘 530 起来后
  面板消失，中间没有空白区（截图 `71-closing-mid.png`）。
- 单测：`收起过渡：restore 档内容先留着；键盘不来 1.8s 后滑出、2.5s 兜底卸载`。
### 14.9 review 补丁（提交前自查）

- **对齐回显**：Univer `getHorizontalAlignment()` 的右对齐返回 **`normal`**（setter 也只收 `left/center/normal`，
  `right` 不被接受）⇒ 读出时统一映射成 UI 的 `right`（`usheetChromeModel.alignOf`，单测覆盖），
  否则「右对齐」按钮永远不高亮；写入仍按内核取值（`setHorizontalAlignment("normal")`）。
- **下划线 / 删除线**：内核表示在不同版本里可能是 `{ s: 1 }` 也可能就是 `1` ⇒ `lineFlagOf` 两种形状都认，
  避免「点了没回显」（`setFontLine` 写入不受影响）。
- 删掉未使用的 `USHEET_READING_ACTIONS`（阅读态动作最终由底栏 + 轻工具条各管各的，没有清单消费方）。
