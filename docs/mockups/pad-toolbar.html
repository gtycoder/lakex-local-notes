要点

双栏：左树 280 常驻，正文限宽 720，右大纲 220 可关；顶栏 = 笔记本切换 + 文档页签 + 搜索/同步/设置。
工具栏：文档用内核固定工具栏（桌面同款 items，放不下的进「…」），命中区 36–40。
单栏：同一套组件，去掉侧栏、内容居中，胶囊保留（P0 的最低成本形态）。
表格：Univer ribbon（页签 32 + 工具行 40 + 公式栏 30），桌面级分组。
多维表：视图页签 + 8 项文字按钮 + 添加记录，均为桌面同序。
手写板：桌面单行工具条（笔/高亮/橡皮 + 8 色 + 4 笔宽 + 撤销 + 导入 + 缩放）。
断点：≥1280 三栏 · 1024 收右栏（正文 764）· <800 回落单栏。

2 小时前编辑项目笔记1,284 字

平板上编辑的体验，首先取决于工具栏。文字工具、插入入口、历史与查找都应该像桌面一样摊开，而不是藏进一个底部面板。

为什么先做工具栏

手机端把内核的固定工具栏关掉，用底部 dock 代替；平板宽度足够，可以直接把它打开：同一套 items、同一套折叠逻辑，放不下的自动进「…」。

  • 桌面已有的段落样式、字号、颜色、对齐、列表、缩进、行高全部可用；
  • 插入入口回到内核的全量面板（含表格、图片、附件、画板、公式）；
  • 触屏命中区从 26 放大到 36–40，下拉行高 44。
双栏时左树常驻、正文限宽 760；右栏大纲可随时收起。手机端 IA 不变，平板是同一套组件的另一个外壳。

正文保持 16px / 1.8 行高，阅读宽度 720px——在 1280 的屏幕上不会被拉成一行 1200 字。

// 工具栏折叠的行为就是桌面行为 toolbar.agentConfig.default.items = [...] // 1280 宽、树 280 + 大纲 220：约 19 项可见，其余进「…」

这是 P0「体面单栏」：同一套组件，不做双栏，内容限宽 760 居中；工具栏已经换成内核那一套，底部胶囊按需保留。

它解决什么

把「大号手机」先修到体面：内容不再横向拉满、面板不再是全宽横条、设置子页不再是一条 440 宽的白板。

  • 断点 600 / 800：≥800 才考虑双栏；
  • 浮层改居中卡片（≤560）；
  • 工具栏与桌面同源。
没有侧栏时，目录/大纲仍从顶栏按钮打开，做成 380 宽的左侧浮层——不是全屏抽屉。

在 1280 的屏幕上，760 的正文两侧各留约 250px，观感接近桌面的正文栏。
