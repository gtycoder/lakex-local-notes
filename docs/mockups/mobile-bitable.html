本轮要验证的三件事

  • 打开默认只读，默认落在表单（填写）视图
  • 表单可提交 = 新增一条记录；其他数据只读
  • 内容视图两套布局：表格 / 卡片（视图配置 → 布局）

快速跳到某个状态

钉钉的对应关系

  • 钉钉「表单」默认进编辑表单（有权限时）；我们默认进填写
  • 钉钉「内容」= 表格视图 + 记录展示方式（卡片 / 表格）
  • 钉钉视图配置 = 筛选 / 排序 / 布局（底部面板，改完立即生效）
  • 钉钉记录详情 = 全屏页 + 1/N 翻页；我们只读态去掉编辑入口
