## Follow-up verification: 2026-08-20 fixed library persistence

Regression reproduced from the reference GIF: `Sidebar` always called the floating-preview leave handler, and that handler unconditionally set the mode to `collapsed` after its timer. A docked sidebar therefore collapsed when the pointer left its surface.

Fix:

- Added an explicit mode guard: only `floating` can collapse on hover leave.
- The delayed callback re-checks the current mode before changing state, so a transition to `docked` during the delay is safe.
- Added a regression test for `floating`, `docked`, and `collapsed` modes.

Real Electron verification:

```text

sidebar mode: docked (unchanged)
```
