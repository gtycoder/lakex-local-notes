## 移动端

- **插入链接可正常输入**（此前输入框点不进字）。
- **＋ 展开面板时编辑区不再跳走**（修复此前键盘与面板切换时序导致的正文跳位）。

# LakexLocalNotes v1.3.5

维护版本：**端口方案简化**——固定端口，正式与开发分开；撤销 v1.3.4 的「资产 URL 端口归一化」复杂化。

## 端口：固定 + 测试/正式分开

- 资源服务（图片/附件）：**正式 19876 / 开发 19877**；Web 客户端：**正式 19880 / 开发 19881**；可用 `LAKE_ASSET_PORT` / `LAKE_WEB_PORT` 覆盖。
- **不再自动回退**：端口被占用时明确报错（日志/设置页可读），不静默降级。
- 为什么这样就够：同一构建形态端口固定 ⇒ 正文里的资产 URL 永远指向同一端口 ⇒ 换实例/重启不会改 contentHash、不会触发同步更新；dev 与正式的数据目录与端口都分开，互不干扰。
- **已回退**：v1.3.4 的保存时资产 URL 归一化（`canonicalizeNoteAssetUrls`、渲染层 strip 端口/token）、v1.3.3 的端口归一化契约、`--lake-asset-port` 传参、`ASSET_PORT_FALLBACK_RANGE` / `WEB_API_PORT_FALLBACK_RANGE` 自动回退、相关测试与 S3 假桶脚本/文档。
- **保留**：`currentAssetServerPort()`（启动时解析一次的固定值，store/导出/小记 URL 使用）、403 对允许 origin 回显 ACAO、资源服务安全面。

## 升级说明

- 无数据迁移。若之前跑过 v1.3.4，正文可能已被归一为 19876（正式版端口），本版正式版继续使用 19876，无影响；开发版正文仍按开发端口 19877 书写。
- 同机同时跑开发版与正式版时，两边端口/数据目录都分开；同一形态双开第二个实例会明确报端口占用。

# LakexLocalNotes v1.3.3

维护版本：**新建文档位置可配置**、**S3 同步后的图片坏链风险修复**、**移动端便携包导出可恢复**。

## 新建文档位置（桌面）

- 设置 → 常规 新增「**新建文档位置**」：**顶部新增 / 末尾追加**（默认末尾追加，与旧行为一致）。
- 作用范围 = **同级插入**，且**子级同样生效**：文档、表格、多维表、画板、手写板，以及**新建分组（目录）/ 新建笔记本**都按它落位。
- 实现上把「顶部 = 同级整体后移再插 0 / 末尾 = MAX+1」的排序逻辑抽成单一实现（`electron/treeSort.ts`），文档（两表同事务）与目录/笔记本共用，不再各写一份 SQL；旧存档/非法值自动回落「末尾追加」。
- 边界：AI 生成文档与批量导入仍固定末尾追加（避免打乱导入顺序）；移动端新建仍末尾追加（该设置是桌面偏好）。

## S3 端口归一化（v1.3.3 引入，v1.3.5 已回退）

- v1.3.3 曾尝试「保存/上云归一规范端口 + 渲染实际端口」的复杂契约；**v1.3.5 已整体回退**，改为固定端口方案（正式 19876 / 开发 19877），同构建形态端口固定即可保证正文 URL 不随实例变化。
- 相关脚本（`scripts/fake-s3-local.mjs` / `scripts/s3-config-zero-regression.mjs`）与审计文档（`docs/SYNC-S3-VERIFY.md`）已删除。

## 移动端卸载/换机备份（D 项）

- 设置 → 关于 →「卸载与换机」新增「**导出便携包到文件**」：快照写到系统「下载」目录（**卸载后文件仍在**），重装后可从「备份与恢复 → 从便携包导入」**整机恢复**。
- 恢复走原生事务：校验（缺 manifest/缺库直接拒绝、不动本机数据）→ 隔离当前库与快照目录 → 拷回 → 提交；失败自动回滚，异常中断由启动 pending 兜底；快照含历史/草稿/同步基线，**不含 S3 密钥**（换机后需重配 S3）。
- 修掉两个真实 bug：① 之前只「导出」不「可恢复」（手机快照被导入器当作桌面包拒收）；② MediaStore 给 `.zip.lln` 追加 `.zip` 导致导入器认不出，现已改用自定义 MIME。
- 设备实测（Android API36 模拟器）：导出 16.8KB → 卸载后文件仍在 → 重装 → 恢复，恢复后 DB 三表与小记正文 sha256 与快照**完全一致**；坏包被拒不伤数据。

## 升级说明

- 无数据迁移；旧设置自动兼容（新建位置缺省末尾追加；检查频率旧 6/12 已在上一版收敛）。
- v1.3.5 起改回固定端口方案：正文资产 URL 始终指向本构建形态的固定端口，无需任何归一化处理。
- 移动端恢复会覆盖本机数据（有回滚副本兜底）；跨大版本 schema 未做迁移，建议同版本恢复。

# LakexLocalNotes v1.3.2

维护版本：**Android 卸载/换机时更容易保住数据**，并补齐移动端说明。

## Android 卸载保留数据

- 应用声明 `android:hasFragileUserData="true"`：**Android 10 及以上**从系统卸载确认框（应用信息或启动器卸载菜单）卸载时，会出现「**保留应用数据**」选项；勾选后重装，本机正文/附件/索引仍在。
  - 限制（如实）：Android 9 及以下没有该选项；静默卸载（adb、应用商店）不会询问；勾选保留后**重装必须同一签名与来源**（正式版与开发版签名不同，不能交叉安装）。
  - Android 10 在「可移除 SD 卡设为便携存储」的机型上有系统级已知缺陷（勾选保留可能卸载失败），见文档。
- 设置 → 关于 新增常驻「卸载与换机 / 卸载前请先备份」：卸载会删本机数据、云同步只是镜像；备份出口 = 桌面版「备份与恢复 → 导出便携包」或确认云同步完成。
