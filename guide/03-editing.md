## 桌面工具栏

从左到右：

| 按钮 | 作用 |
| --- | --- |
| ＋ | 打开插入面板，插入图片、附件、表格、引用、代码块、公式、分栏、折叠块等（按文档类型给可用项） |
| 撤销 / 重做 | 回退或重做上一步编辑 |
| 清除格式 | 去掉选中文字的格式，回到正文 |
| 标题级别 | 正文、标题 1 到标题 6 |
| B / I / S / U / 代码 | 加粗、斜体、删除线、下划线、行内代码 |
| 文字颜色 / 高亮 | 选色板给文字上色或加底色 |
| 列表组 | 无序列表、有序列表、待办、对齐方式、缩进 |
| 复选框 | 插入待办项 |
| ⋯ | 更多块操作（与块句柄菜单一致） |

> 「设置 → 编辑器」里可以关掉固定工具栏，改用选中文字时弹出的浮动工具栏。

## 段落与块

文档由「块」组成：一行文字是一个段落块，列表、引用、代码块、图片都是块。块能做的事：

- **转换成别的块**：光标在块里，用工具栏的标题级别或块句柄菜单的「转化为」（正文 / 标题 / 列表 / 引用 / 代码块 / 高亮块 / 分栏 / 折叠块等）
- **移动与复制**：鼠标移到行首会出现块句柄，可上下拖动移动；句柄菜单里能复制、剪切、删除、在下方添加
- **多选**：按住 Shift 点选或拖选多行，可批量转换或删除

## 支持的块类型

- 标题 1 到标题 6、正文段落
- 无序列表、有序列表、待办列表（可勾选）
- 引用、代码块、高亮块
- 分割线、分栏、折叠块
- 表格（见 [04](04-sheet.md)）
- 图片、附件、视频、音频
- 文档引用（把一个文档作为卡片插进另一个文档）
- 公式、思维导图、画板、加密文本等卡片

## 图片与附件

- 通过插入面板或直接粘贴图片进文档
- 附件支持常见文档、压缩包等类型，点击用系统默认应用打开
- 图片显示大小可调；「另存为」「在文件夹中显示」在右键菜单或图片工具条里
- 附件与图片存放在本机数据目录的 `note-assets` 下，随文档一起同步（如已开启云同步）

## 保存

- 编辑时**自动保存**，不需要点保存按钮
- 底部状态栏与目录行的状态点显示同步状态：没有启用云同步时是「仅本地」；启用后会出现「待同步」（有改动还没上传）、「已同步」、「同步中」等
- 关闭标签、切到别的文档都不会丢内容

## Android 编辑

<p><img src="assets/screenshots/android-editor.png" alt="Android 编辑态" width="320"> <img src="assets/screenshots/android-dock-panel.png" alt="插入面板" width="320"></p>

- 点顶栏铅笔进入编辑，右上角勾号退出编辑
- 底部工具条：「＋」插入、T 字体（标题/正文等）、B 加粗、列表、待办、「⋯」更多、撤销、重做、键盘
- 插入面板是方块网格，可插入拍照、图片、附件、音频、视频、表情、状态、日期、表格、引用、分割线、代码块、高亮块、分栏、折叠块、链接等
- 手机上没有桌面那样的固定工具栏，也没有块悬浮手柄与斜杠面板；能输入的内容就是底部工具条与插入面板里有的那些

## 复制粘贴

- 桌面与 Android 都支持从别处粘贴文字与图片
- 粘贴纯文本时保留换行；粘贴富文本时尽量保留格式
- 表格、多维表里的单元格粘贴按行列展开（见对应章节）

## 专注写作

- `⌘⇧Enter` 进入或退出专注模式，隐藏多余界面元素
- `⌘]` 收起或固定目录栏
