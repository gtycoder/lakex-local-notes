# 13 快捷键

[← 返回目录](README.md) | 上一章：[12 设置项逐条](12-settings.md) | 下一章：[14 常见问题 →](14-faq.md)

当前版本的快捷键是**固定的**（参考思源的口径），**暂不支持自定义**（设置 → 快捷键里可以看到这份清单）。macOS 用 `⌘`，Windows / Linux 用 `Ctrl`。

## 全局

| 快捷键 | 作用 |
| --- | --- |
| `⌘P`（或 `⌘K`） | 打开全局搜索（标题和正文） |
| `⌘N` | 新建文档（知识库：弹窗输入标题；日记：今天新建一篇；其它空间会先回知识库） |
| `⌘⇧Enter` | 进入或退出专注模式 |
| `⌘]` | 收起或固定目录栏 |
| `⌘1` – `⌘5` | 切到一级空间：知识库 / 小记 / 日记 / AI 写作 / 标签 |
| `⌘,` | 打开偏好设置 |
| `Esc` | 关闭当前菜单或浮层 |

## 标签页

| 快捷键 | 作用 |
| --- | --- |
| `⌘W` | 关闭当前标签（文档与日记标签同一个语义；没有打开标签时不动作） |
| `⇧⌘[` / `⇧⌘]`（或 `⌃⇧⇥` / `⌃⇥`） | 上一个 / 下一个标签（只在本空间的标签之间循环） |
| `F9` | 立即同步（未配置 S3 或已关闭云同步时会给出理由，不会静默失败） |
| `⇧⌘G` | 锁定 / 解锁当前文档（只读；锁定只拦本地编辑，不拦同步） |
| `⌥H` | 打开当前文档的历史版本 |

## 搜索结果里

| 快捷键 | 作用 |
| --- | --- |
| `↑` / `↓` | 在搜索结果中移动 |
| `Enter` | 打开搜索结果并定位命中 |
| `⌘Enter` | 在新标签打开并定位命中 |

## 编辑

| 快捷键 | 作用 |
| --- | --- |
| `⌘F` | 文档内查找（使用编辑器自带的查找面板） |

> 复制、粘贴、全选、撤销这类通用编辑快捷键沿用系统与编辑器的默认行为。

## 说明

- **不采用思源「⌘1–9 切标签」**：`⌘1`–`⌘5` 在这里是一级空间切换（已在设置与手册里登记，沿用不动）。
- `⌘W` 只关标签、不关窗口；最后一个标签关掉后停在空态。
- 平板（外接键盘）是另一套最小集（`⌘K` 搜索 / `⌘F` 查找 / `N` 新建），见平板说明；手机以触屏为主，不提供快捷键。

## Android

- 手机端以触屏为主，不提供自定义快捷键
- 文档内查找在工作区顶栏的放大镜里（没有键盘时也能用）
- 外接键盘时，文本编辑类快捷键由输入法与系统处理
