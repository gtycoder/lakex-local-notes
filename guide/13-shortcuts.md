# 13 快捷键

[← 返回目录](README.md) | 上一章：[12 设置项逐条](12-settings.md) | 下一章：[14 常见问题 →](14-faq.md)

当前版本的快捷键是**固定的，暂不支持自定义**（设置 → 快捷键里可以看到这份清单）。

## 全局

| 快捷键 | 作用 |
| --- | --- |
| `⌘K` | 打开全局搜索（标题和正文） |
| `⌘⇧Enter` | 进入或退出专注模式 |
| `⌘]` | 收起或固定目录栏 |
| `Esc` | 关闭当前菜单或浮层 |
| `⌘,` | 打开偏好设置 |

## 搜索结果里

| 快捷键 | 作用 |
| --- | --- |
| `↑` / `↓` | 在搜索结果中移动 |
| `Enter` | 打开搜索结果并定位命中 |
| `⌘Enter` | 在新标签打开并定位命中 |

## 空间切换

| 快捷键 | 作用 |
| --- | --- |
| `⌘1` | 切到资料库 |
| `⌘2` | 切到小记 |

## 编辑

| 快捷键 | 作用 |
| --- | --- |
| `⌘F` | 文档内查找（使用编辑器自带的查找面板） |

> 复制、粘贴、全选、撤销这类通用编辑快捷键沿用系统与编辑器的默认行为。

## Android

- 手机端以触屏为主，不提供自定义快捷键
- 文档内查找在工作区顶栏的放大镜里（没有键盘时也能用）
- 外接键盘时，文本编辑类快捷键由输入法与系统处理
