## 数据与备份

**我的数据存在哪？**
桌面：`~/Library/Application Support/lakex-local-notes/`（开发版是 `lakex-local-notes-dev/`）。菜单「帮助 → 打开数据目录」可直接打开。Android 在应用私有目录里，卸载应用会一起删除。

**怎么整体备份？**
桌面「设置 → 云端与同步 → 整库备份到…」导出数据库、全部笔记与资源、历史快照和小记。也可以只导出单篇文档。

**换电脑/换手机怎么办？**
两条路，按是否想省 S3 流量选：

- **S3 增量**：老设备上完成一次同步 → 新设备配好同一个 S3（用「配置迁移」的配置文件最快）→ 打开云同步让它拉取。若本机库损坏，用「从云端恢复」，它不会把本机数据上传覆盖云端。
- **便携包**：桌面「设置 → 备份与恢复 → 导出便携包」得到一个 `.zip.lln`（≤4GiB、不含历史快照），传手机后「从便携包导入（覆盖本机）」，之后再把 S3 接上只做增量。没配 S3 也能用。

三条路的边界对比见 [18 换机、便携包与迁移](18-portable-and-migrate.md)。

## 同步

**同步失败怎么办？**
先「测试连接」看是密钥、桶名、区域还是权限问题；再打开顶部同步状态看失败分类与原因。手机端在设置 → 云端与同步里能看到上次同步的时间与结果。

**两台设备改了同一篇文档会怎样？**
同步时先拉远端：**远端已发布的版本胜出**，被覆盖的一方不会丢内容，会自动留一份历史快照（见 [09](09-history-trash.md)）。移动/删除与正文编辑互不覆盖，见 [11 多端同步的正确表现](11-cloud-sync.md#多端同步的正确表现)。

**同步提示「有 N 项被跳过」怎么办？**
这是同步**有意跳过**了某些条目，其它内容照常同步。你会看到类似「同步有 3 项被跳过（需处理 1，可重试 2）」的摘要，这两类数字的处理方式完全不同：

- **可重试（自己会好，通常不用管）**：下一轮同步会再试。包括「远端内容不完整」（这一篇先跳过，本地内容没动）、「附件在云端缺失」（只跳过该文件）、「本机附件读不出」（保留云端声明，避免误删云端附件）；另有一类是「已从云端恢复正文」，表示本机缺的正文已经拉回，可直接继续编辑。
- **需处理（不会自己好，要你动手）**：
  - **本机正文文件缺失**：同步不会上传空正文。请从「历史版本」或云端恢复这篇，再继续编辑。
  - **正文疑似被外部改坏**：同步已停止上传并保留了历史。先在「历史版本」里确认哪一版是对的，恢复正确版本后再继续编辑。
  - **文件名不合法**：这个附件被跳过。把附件改名（或重新插入一份名字正常的文件）后再同步；如果仍被跳过，把「同步诊断」里的这一条发给维护者。

在哪看：桌面点顶部同步状态，摘要下面会列出前 5 条（可直接点开对应文档），更多点「查看同步诊断」（设置 → 云端与同步 → 同步诊断，最近 3 轮含逐项原因）；手机端在设置 → 云端与同步里看同一份摘要和逐项说明，缺正文的行可直接点「去恢复」。

**为什么状态显示「仅本地」？**
说明云同步没配置或没启用。关闭云同步 = 完全没配置，应用不会出网，数据只在本机。

**一端删了，另一端还显示着这篇？**
删除 = 把这篇移进「回收站」这本笔记本，属于**位置变更**；位置变更会传播，但只有**同步过之后**才会传播到另一端。所以最常见的原因就是那台设备还没同步：在它上面点一次「立即同步」（桌面顶部同步状态；手机顶栏的云图标）。同步后它要么消失，要么（那台之前就持有副本时）留在回收站并标「云端已删除（仅本地）」，那是最后一份可恢复副本；从未有过副本的设备本来就没有这篇。这期间另一端对正文的编辑也不会丢（内容归远端、位置归本地）。

原理和「移动 / 编辑锁 / 冲突」的完整判断表见 [11 多端同步的正确表现](11-cloud-sync.md#多端同步的正确表现)。

**「启用云同步」点不开 / 点了没反应？**
需要先完成 S3 配置并「测试连接」通过。没配好时点击只会提示，不会开始同步。

**云端是另一套数据？**
不会。云端只是本机数据的镜像，且以本机为准；同步不合并冲突，冲突时远端已发布的版本胜出，被覆盖的一方留历史快照（先同步上去的那版赢）。

## 文档与编辑

**提示「正文文件缺失」怎么办？**
这是正文文件被外部删除或损坏时的保护：文档会以只读方式打开，并给出三个选择（从云端拉回、恢复最新历史、关闭标签）。云端有副本时可拉回；没有副本时只能从历史或备份恢复。

**文档突然变成只读了，怎么解除？**
先看编辑器顶部横幅写的原因，几种常见原因的处理方式不一样（「正文文件缺失」见上一条）：

| 横幅写的原因 | 为什么会这样 | 怎么解除 |
| --- | --- | --- |
| 该文档在回收站中 | 你或别的设备把它移进了回收站（软删除），回收站里的东西不能编辑 | 到回收站里「恢复」，恢复后就能继续写 |
| 云端已删除（仅本地） | 别的设备**彻底删除**了它，本机这份是最后副本 | 到回收站里「恢复」，恢复后会重新上传回云端 |
| 本文档已锁定（只读） | 某台设备给它加了**编辑锁**（防止误改），锁会随同步传播 | 在加锁的那端解锁：桌面点文档右下状态栏的锁提示 →「解锁」，或用目录行右键 / 顶栏「更多」里的「解锁当前文档」。手机端只显示只读横幅，解锁请到桌面做 |

- 编辑锁**不影响同步**：它只锁「编辑」，文档照样同步、照样能被恢复；锁也不等于删除或移走。
- 「云端已删除（仅本地）」的副本不参与上传，只有你显式恢复才会回到云端（见 [09](09-history-trash.md)）。
- 手机端遇到锁：打开会提示「文档已在桌面端锁定（只读）」，保存会被明确拒绝 —— 这是设计如此，不是 bug。

**彻底删除一个分组后，里面的文档去哪了？**
在回收站里把**含子文档的分组**（或笔记本）彻底删除时，**整棵子树会一起被彻底删除**：里面的文档、子分组、正文与附件、历史快照都会被删除，**无法恢复**。

- 对比：平时「删除」只是把分组移进回收站（软删除），里面的东西一起进回收站，**可以整棵恢复**；**只有「彻底删除」才是永久删除**。
- 云端也会一起清理：这些文档不会再出现在其它设备上（见 [11 多端同步的正确表现](11-cloud-sync.md#多端同步的正确表现)）。
- 其它设备如果之前就持有这些文档的副本：只会留在**各自**的回收站里并标「云端已删除（仅本地）」，**不会自己回传复活**（只有你在那台设备上显式点「恢复」，才会重新回到云端）。
- 想留底：彻底删除前先导出一份（单篇导出或整库备份），并确认回收站里没有你还想留的内容。

> 回收站、历史快照与「云端已删除（仅本地）」的细节见 [09 历史快照与回收站](09-history-trash.md)。


**打开文档看不到最新内容？**
先确认是否在别的设备上改过，同步一次再看；也可以看「历史版本」确认是否有更新版本被覆盖。

**数据不对劲（搜不到、数量不对、提示缺正文）先做什么？**
按顺序试三个自愈入口，都是只读或可回退的：

1. 设置 → 数据维护 →「一致性检查」：只读体检正文文件、历史快照、未归属记录与引用资源
2. 设置 → 数据维护 →「重建全文搜索索引」：搜索明显搜不到刚写的内容时跑
3. 设置 → 数据维护 →「重建数据」：正文文件还在、笔记行丢了时，从正文补回元数据行

坏库（打不开、崩溃循环）走「备份与恢复 → 从云端恢复」或「从数据库快照恢复」（开发者口径见仓库 `docs/RESILIENCE.md`）。

**表格部分内容截图是空白？**
表格绘制在 GPU 画布上，页面截图可能抓不到。请用系统截图（macOS `⇧⌘4`，Android 电源键组合）验收。

## 小记

**保存和保存并同步有什么区别？**
「小记一下」只存本机，不立刻上传；「保存并同步」会立刻发起一次同步。云同步未配置时后者置灰并说明原因。

**小记回收站在哪？**
Android：设置 → 回收站里的小记分页；桌面回收站也分「文档 / 小记」两页。彻底删除后不可恢复。

## AI

**AI 开关点不动？**
需要先保存接口、模型与 API Key，并「测试连通性」通过。未通过时点击开关只会提示。

**AI 会不会把笔记上传到别处？**
只会把你要处理的文本发给你自己配置的供应商；API Key 只存本机，不参与同步与备份。

## Android

**手机上能编辑表格和多维表吗？**
表格支持查看与基础编辑，多维表以只读表格展示；完整编辑请在桌面端做，改动会同步过来。

**清空应用数据会怎样？**
等于全新安装：本机数据全部删除。若已开启云同步，再次配置同一个 S3 后可「从云端恢复」。
