# 20 使用技巧

[← 返回目录](README.md) | 上一章：[19 更新中心](19-update-center.md)

把高频场景里「省流量、省时间、少踩坑」的用法集中在这一章。每条 = 一句话说清价值 + 步骤要点 + 详细章节入口；界面文案以你安装的版本为准。

## TIP-01 换机先用便携包：省下 S3 首轮全量的流量费

**价值**：新设备首次同步要从 S3 传/拉全库（按 GB 计费的桶上是真金白银）；便携包走本地文件搬全量，之后配好 S3 只做增量。

1. 老设备先确认完成过一次同步
2. 设置 → 备份与恢复 →「迁入迁出（便携包）」→ 导出便携包，得到一个 `.zip.lln`（上限 4GiB；已开云同步时导出前会自动同步一次，失败不出包，包内带同步基线）
3. 把文件带到新设备，「从便携包导入（覆盖本机）」
4. 用迁移码把 S3 配置搬过去（TIP-03），打开云同步——从此只做增量

详见 [18 换机、便携包与迁移](18-portable-and-migrate.md)；第二条省流路径是 [11 云同步](11-cloud-sync.md) 里的「按需下载附件」。

## TIP-02 三种备份 / 迁移怎么选：先看这张决策表

**价值**：选错路白折腾——动手前先想清楚「要搬什么、走哪端」。

| 需求 | 走哪条 |
| --- | --- |
| 跨端换机、想省 S3 流量 | 便携包 `.zip.lln`（不含历史快照与 AI 会话） |
| 同端换机 / 大库 / 要历史快照 | 整库备份目录（无 4GiB 限制，含历史快照） |
| 只防坏库 | 自动备份（仅数据库，每天或每周一份） |
| 已有桶、持续增量同步 | S3 云同步 |

详见 [18](18-portable-and-migrate.md) 的「几条路怎么选」。

## TIP-03 S3 配置迁移码：免手填，但别外传

**价值**：Endpoint / Region / Bucket / 前缀 / 密钥五段手填易错，配置文件或迁移码一键搬。

1. 桌面：设置 → 云端与同步 →「同步服务配置」→「导出」，得到只含 S3 配置的 `.json`（密钥已加密）
2. 发到手机：设置 → 云端与同步 →「配置迁移」→「从文件导入」选它，或「粘贴迁移码…」粘贴 `LLN1.` 开头的迁移码
3. 导入会**覆盖**本机 S3 配置；导入后先「测试连接」再开云同步

⚠️ 迁移码的内层加密**只防误读、不是安全边界**（固定种子），别贴到聊天工具。详见 [11 配置迁移](11-cloud-sync.md#配置迁移)。

## TIP-04 关闭云同步 = 零出网的隐私姿势

**价值**：想要「纯本地、一个字节都不出网」不用断网——关掉「启用云同步」即可（AI 助手另有独立开关）。

1. 设置 → 云端与同步 → 关「启用云同步」，界面回到「仅本地」
2. S3 配置与本地数据都保留，随时重开继续增量

注意：没通过「测试连接」本来也开不了（先测试后开启的闸门）。详见 [11 关闭云同步](11-cloud-sync.md#关闭云同步)。

## TIP-05 AI 隐私：会话不进同步、不随包、Key 只在本机

**价值**：用 AI 又不想内容外泄或跟着换机走，先知道边界在哪。

- 请求只发给你自己配的供应商，不经过本项目中转
- API Key 只在本机加密保存，不进笔记、备份、便携包与云同步
- 桌面 AI 助手对话**只在内存**，关面板即清空；AI 写作会话只存本机（不进云同步、便携包不含、换机不跟）
- 想留住结果，就把它落进文档（落进正文的才有保存与历史版本）

详见 [10 AI 助手](10-ai.md) 与 [17 AI 写作](17-ai-writing.md)。

## TIP-06 Android 卸载保留数据：勾一下，省一次重装迁移

**价值**：清完空间还要装回时，不用重新导数据。

1. Android 10+ 从**系统卸载对话框**（应用详情 / 启动器卸载菜单）卸载
2. 勾「保留应用数据」→ 同包名、同签名同来源重装后数据还在

⚠️ 长按图标拖走、adb 卸载都不弹这个选项，Android 9 及以下没有该能力；不保险就先「导出便携包到文件」（落到系统「下载」目录，卸载后仍留存）。依据见 [14 常见问题](14-faq.md) 与 [18](18-portable-and-migrate.md)。

## TIP-07 画板素材库：常用图形做成可复用素材

**价值**：流程图里的固定组件（架构图例、表单框）不用每次重画。

1. 画板「素材库」面板 →「打开素材文件夹」，打开数据目录的 `materials/`
2. 框选要复用的图形 → 右键「添加到素材库」命名保存；自己往文件夹放 `.board.json`，下次打开面板自动列出
3. 「插入素材」复用；插入画板并**保存后**，图片才成为该画板的资产

⚠️ 素材不进云同步，但会随便携包 / 整库备份带走；手机端暂用本机兜底、没有「打开素材文件夹」。详见 [06 画板与手写板](06-board-ink.md#画板自定义素材库)。

## TIP-08 日记 ↔ 小记 / 文档互转：写错了空间不用重打

**价值**：随手在日记里写长了、写成资料了，一键挪走，正文卡片零损失。

- 日记条目右键（手机 ⋯）→「转为文档…」选笔记本 = **移动**（同一文档，历史 / 回收站 / 索引跟随）
- 「转为小记」= **复制**正文与图片/附件到小记，原稿进回收站可恢复

⚠️ 表格 / 多维表 / 画板 / 手写板类型的日记只能先「转为文档」；不支持反向移入日记本。详见 [16 日记](16-diary.md)。

## TIP-09 同步记录账本：被覆盖的编辑一键恢复本地版

**价值**：「另一台把我的字盖了」不用恐慌——账本留痕，可一键恢复并重传。

1. 有未读时同步图标带角标：桌面看顶部同步状态里的「同步记录」列表，手机看 设置 → 云端与同步 →「同步记录」
2. 对被覆盖的那条点「恢复本地版」——从历史快照取回你那一版，下次同步按本机版本上传覆盖云端

后台同步永远不弹窗，只给角标 + 列表。详见 [11 同步记录（冲突账本）](11-cloud-sync.md#同步记录冲突账本)。

## TIP-10 编辑锁当「防误改」用：一处上锁、全端只读

**价值**：给定稿或借出去的文档加只读锁，锁随同步传播到所有设备，不用挨台设。

1. 文档右键「锁定（只读）」（`⇧⌘G`），各端同步后都只读；解锁走同一入口

⚠️ 锁**只锁本地编辑、不拦同步**（别的设备照样能改并同步进来），锁不是「停止同步」；想让某台设备完全不出网用 TIP-04。详见 [02 笔记本与目录](02-notebooks.md) 与 [11 多端同步的正确表现](11-cloud-sync.md#多端同步的正确表现)。

## TIP-11 长按与批量：手机上的效率入口

**价值**：手机整理几百条不靠一条条点。

1. 长按桌面图标的三个快捷入口：拍照小记 / 剪切板小记 / 新建小记（前两者整份替换未提交草稿，取消不动草稿）
2. 首页「＋」长按约 260ms 后上滑 = 直接进速记写作卡
3. 长按文档行进入多选（上限 500），批量移动 / 打标签 / 移入回收站
4. 长按笔记本卡片 = 编辑菜单（含「收起」）

详见 [07 小记](07-quick-notes.md)、[02 笔记本与目录](02-notebooks.md)、[15 导入、批量操作与导出](15-import-export.md)。
