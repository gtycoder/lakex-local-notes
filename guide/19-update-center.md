# 19 更新中心

[← 返回目录](README.md) | 上一章：[18 换机、便携包与迁移](18-portable-and-migrate.md)

应用内置更新中心：帮你**发现**新版本、下载安装包、看更新内容，但**绝不会背着你安装**。

| 平台 | 入口 |
| --- | --- |
| 桌面 | 设置 →「更新」（独立分类页，不是弹窗） |
| Android | 设置 →「更新中心」（菜单倒数第二项，「关于」上方） |

## 桌面：设置 → 更新

| 分组 | 内容 |
| --- | --- |
| 版本与检查 | 「当前版本」显示版本号与上次检查时间，右侧是「检查更新」按钮；「状态」显示上次检查/下载的结果 |
| 可用更新 | 只在发现新版本时出现：版本号、发布日期、安装包大小、更新内容 |
| 自动更新 | 「自动检查」开关 + 「检查频率」（关闭 / 6 / 12 / 24 小时，默认开、默认 24 小时）；「自动下载」开关（默认开） |
| 更新日志 | 「查看更新日志」直接渲染当前版本及历史版本的更新内容 |

发现新版本时，这一页会出现：

- **下载安装包**：显示下载进度，完成后变成 **打开安装包**（macOS 打开 dmg，Windows 运行 exe）
- **前往发布页**：打开 GitHub Release 的当前最新 tag 页，手动下载的兜底
- **忽略此版本**：这个版本不再提示；下个版本会恢复提示
- 也可以什么都不做，过一会儿再说

## Android：设置 → 更新中心

同样四行，另加一行：

- 检查更新 / 自动检查（含间隔）/ 自动下载 / **仅 Wi-Fi 自动下载**（默认开）/ 更新日志
- 发现更新后是**更新卡片**：版本、大小、更新内容 →「下载并安装」→ 进度 →「安装」→ 拉系统安装器，由你在系统弹窗里确认
- 后台自动下载走系统下载，系统通知里能看到；回到应用后会提示安装

## 它不会自动装

这是刻意的设计，三点都别期待：

1. **不做静默安装**：桌面下载完要你自己点「打开安装包」；Android 最后一步必须在系统安装器里确认
2. **手动检查不会自动下载**：你自己点「检查更新」只得到提示，下载还是由你决定
3. **自动下载只在后台自动检查时发生**（默认开）：发现即下，下完仍然等你安装；Android 默认只在 Wi-Fi 下自动下载

自动检查的时机：应用启动时查一次，之后按间隔在后台查。桌面设置只保存在本机，不进云同步、不写进笔记。

## 检查与校验

- 更新源是 GitHub Releases 的稳定版（没有测试通道），清单和安装包都只走 HTTPS
- 下载完成后会校验 **sha256**；Android 还会额外核对安装包的签名证书指纹。校验失败会删掉坏包并提示重新下载
- 下载中断或中途关掉应用：重新打开后能接着用已下载的包（若已下完），或重新下载（最多重试 3 次）
- 清单里的版本比当前版本低（例如被撤回）**不会**提示降级

## 出问题时

- 网络失败时状态行会把错误翻译成一句**能照着做的话**（比如连接 GitHub 超时、请检查代理或 VPN 后重试），并在末尾保留原始错误码，方便排障和反馈
- 国内直连 GitHub 可能很慢：可以关掉自动检查、隔一阵手动点一次，或直接去「前往发布页」用浏览器下载
- 自动检查和手动检查不会同时跑（同一时刻只跑一个）
- 提示「已忽略此版本」时，用「检查更新」仍能看到它，只是不会再弹
