# 07 小记

[← 返回目录](README.md) | 上一章：[06 画板与手写板](06-board-ink.md) | 下一章：[08 搜索、大纲与标签 →](08-search-outline-tags.md)

小记是随手记的地方：不用先想放哪个笔记本，写完可以留在小记里，也可以转成正式文档。

![桌面小记](assets/screenshots/desktop-quicknotes.png)

## 打开小记

- 桌面：左上空间菜单 →「小记」（或按 `⌘2`）
- Android：首页底部 Dock 第 1 格「小记」
- 手机速记有两级：中央「＋」**短按**打开新建面板；**长按约 260ms 后上滑**直接进全屏速记写作卡（不用先回首页）
- Android 还可以长按桌面图标用「新建小记」静态快捷方式直接进写作卡：这一次会话属于「专心的写作」，不会自动发起同步

## 写作卡

左侧卡片是写作区，顶部一排小工具：

| 工具 | 作用 |
| --- | --- |
| 日期 | 插入当前日期 |
| 表情 | 插入表情 |
| 图片 / 附件 | 插入图片或附件 |
| 待办 | 插入待办项 |
| 无序列表 | 插入列表 |
| 分隔线 | 插入分割线 |
| 展开 | 放大写作区 |

写完点「小记一下」保存到时间线，「取消」放弃这次编辑。

## 保存与保存并同步的区别

- **小记一下（保存）**：只把内容保存在本机，**不会立即上传**，也不会「顺手」帮你同步。适合随手记、不着急同步的时候。
- **保存并同步**：只推**当前这一条**，不拉整本索引、不处理别的待同步条目。所以它很快；同一个内容重复点也不会有额外上传。
- 它失败时**不会假装成功**：不会写进同步基线、也不会把这条标成已同步，只会如实告诉你原因，留着稍后重试。
- 云同步没配置或关闭时，「保存并同步」按钮置灰并给出原因；此时只保存本机。

> 只想留在本机就点「保存」——应用**不会背着你**把这一条推上去。想立刻进云端才点「保存并同步」。

## 标签

- 时间线上方是标签栏，标签后面括号里的数字是该标签下小记条数
- 「添加标签」新建标签；点「管理」进入标签管理（重命名、长按拖拽调整顺序、合并、删除；顺序只在本机生效，不同步）
- 一条小记可以有多个标签；点标签即按标签筛选
- 标签是**小记与文档共用**的一套目录：文档标签在文档「属性 / 标签…」里添加，小记标签在写作卡里添加；详见 [08 标签](08-search-outline-tags.md#标签)

## 时间线与筛选

- 每条小记显示正文摘要与「更新于 时间」
- 右上角图标：搜索、筛选、排序（按更新时间）
- 小记数量较多时先用标签缩小范围

## 转成正式文档

- 小记卡片「⋯」→ 转正式文档：把小记内容变成一篇文档，放进你选择的笔记本，之后可以继续在文档里写
- 转换后原小记如何处理，以转换时的界面提示为准

## 删除

- 卡片「⋯」→ 删除：小记进入**小记回收站**，可在设置里找回
- 小记回收站与文档回收站分开；彻底删除后不可恢复

## Android 上的小记

<p><img src="assets/screenshots/android-home-quicknotes.png" alt="Android 小记时间线" width="320"></p>

- 首页「小记」是时间线，卡片右侧「⋯」可编辑、加标签、转文档、删除
- 卡片内容里的表格、代码块、公式、画板等复杂块，会用只读预览完整显示（不能直接改）
- 列表卡与预览里的图片默认按缩略图（1024px）显示，看原图才取原件；流量紧张可以在设置里开「按需下载附件」
- 卡片封面用的就是正文第一张图时，预览里不会再把同一张图重复画一遍
- 首页 Dock 中间的「＋」是小记与文档共用的新建入口
