# 导入、批量操作与导出

本篇讲三件相关的日常操作：**导入 Markdown**、**多选批量操作**、**批量导出**。当前版本支持导入 Markdown；Word / Excel 导入尚在计划中（见文末）。

## 导入 Markdown（桌面）

入口：目录栏（或顶部）的 **＋ → 导入 → Markdown…**。

1. 可以一次多选多个 `.md` 文件；**不支持拖拽导入**（用 ＋ 可以明确导入到哪个笔记本/分组）。
2. 目标位置 = 你点击 ＋ 时所在的笔记本或分组；顶部 ＋ 需要先打开一篇文档（否则菜单项置灰并提示）。
3. 导入时会显示「正在导入 N/M：文件名」，可以取消（已导入的文档会保留）。
4. 支持标题、段落、加粗/斜体/删除线/行内代码、链接、有序/无序/嵌套列表、任务列表、引用、代码块、GFM 表格、分隔线、公式、中文与 emoji。
5. 图片：本地相对路径图片会导入为文档资产；远程图片当前**不下载**，会降级为链接并在结果里提示。
6. 降级说明：frontmatter（`---` 元信息块）会被丢弃；脚注语法会降级为普通文本；块级 HTML 降级为段落。
7. 单个文件上限 20MB；不支持的扩展名、超限文件、读取失败会跳过并计入结果。
8. 结果窗口显示「成功 N 篇，跳过 M 个，失败 K 篇」，warnings 可展开查看；失败文档会被移入回收站（不会留下半成品）。

## 导入 Markdown（Android 分享）

1. 在文件管理器或其它 App 里选中 `.md` 文件 → 分享 → 选择本应用；支持一次分享多个文件、冷启动与热启动。
2. 导入位置 = 设置 → **导入 → 默认笔记本**；第一次分享时如果还没设置，会先弹出「选择导入位置」，选完会记住。
3. 导入过程会提示「正在导入 N/M」；失败会明确提示，失败文档会被移入回收站。
4. 手机上分享进来的 md 里的本地图片通常不可达，会降级为链接并提示数量。
5. 分享 PDF 仍进入手写板、分享图片仍进入小记，互不影响。

## 多选批量操作

**桌面**：点击行选中后用 ⌘/Ctrl 点加选、Shift 点选区间；笔记本不能多选（区间会自动跳过）。Esc 或点空白清空。

**Android**：在小记列表或工作区「文档列表」里长按一行进入多选（或页头「选择」）；顶部显示「已选 N / 全选 / 取消」，点行切换选中。

选中后可做：

| 操作 | 说明 |
| --- | --- |
| 移动… | 弹出目录树选择目标（搜索、当前位置高亮、自身/子项禁用）；单条或多条都可 |
| 打标签… | 追加标签（不覆盖已有关联）；桌面可切换追加/移除 |
| 移入回收站 | **软删除**，之后可在回收站恢复；彻底删除只在回收站里做 |
| 导出…（桌面） | 按类型默认格式批量导出，见下节 |

右键菜单（桌面多选时）只有三项：**移动… / 导出… / 移入回收站**（最后一项为危险红）。回收站列表不支持多选与批量操作。

## 批量导出（桌面）

选中若干文档/分组 → 右键「导出…」→ 选择导出目录。分组会递归导出其下的文档。

| 类型 | 默认格式 |
| --- | --- |
| 文档（Lakex） | Markdown 资料包（`<标题>/<标题>.md` + `images/`，图片相对链接） |
| 表格 | CSV |
| 多维表 | CSV |
| 手写板 | PDF（整本压平） |
| 画板 | PDF |

说明：

- 重名会自动追加「 (2)」「 (3)」；单批最多 500 项；导出只读，不会改动原文档或触发同步。
- 画板默认导出 PDF：已打开的画板取当前画面，未打开的会用后台快照；快照失败时该条会标记「跳过」并给原因，不生成坏文件。
- 结果提示「导出 N / 失败 M / 跳过 K」，可直接「打开所在文件夹」。

## 暂不支持

- 拖拽文件导入（用 ＋ → 导入）。
- Word（.docx）与 Excel（.xlsx）导入：已完成调研，等后续排期；Excel 会先支持 CSV。
- Android 端批量导出：系统目录选择受限，请在桌面端导出。
